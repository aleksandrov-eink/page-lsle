# kiikoread 0.3.3-rc99 定制版 · 改版日志与刷机指南

适用机型：RDP-G01-W 墨水屏（ESP32-S3 / 16MB flash）
版本号：**0.3.3-rc99**（应用层定制，分区表 / 引导程序 / otadata 与官方一致，未改动）
本版应用镜像：**3,998,560 字节**（ota_0 槽 4,194,304 字节，余量 **195,744 字节**）
本版 sha256：`fa1a91bf416add07b53c8ebb5361b19134a33dfb98088295fa4626e130c48799`

> 说明：下面是相对**官方原版 0.3.3-rc99** 的改动清单。原版只有固定的竖排选项、单一翻页方式、
> 官方字体与配色；以下均为本定制版新增或修复的、用户可直接感知的变化。

---

## 一、阅读与排版

1. **自适应阅读方向**：原「竖排（从右到左）」选项替换为「自适应阅读方向」。打开后由加速度计
   判定设备朝向，自动在竖屏 / 横屏（两个方向）间切换；所有面板、菜单、工具栏横屏可用。
2. **四档翻页效果**：普通·快刷 / 普通·高清 / 水波纹·快刷 / 水波纹·高清，可分别选择。
3. **字级划线**：正文长按只选中手指下的当前字，手指前滑灰带逐字增长、后滑逐字收回，
   跨行、跨段自动接上，段落间隙也能连续选；松手保存。划线按书 sidecar 保存
   （`/sdcard/.readpico/highlight/` 或内置书的 `/flash` 同名目录），改字号/行距/繁简不移位。
4. **划线列表**：工具栏「划线」查看本书记录，可点行跳转、分页、删除；每行有预设标签
   （无→重要→待读→疑问）；**长按一条记录可写/改/清空笔记**，列表优先显示 `✎ 笔记`。
5. **长按已划线句子直接删除**整段划线（提示“已删除划线”），长按未划线处仍是新建/拖动。
6. **图文书插图预读**：空闲时把下一页插图提前解码进 PSRAM，翻到插图页直接显示。
7. **连续字号滑杆**：阅读字号 1px 步进；字重、行距、缩进、阅读线等原设置保留。
8. **横屏章节页修复**：横屏阅读章节首页会显示紧凑章名横带；修复章名重复一行。

## 二、显示、刷新与反色

9. **反色模式三态**：设置 → 显示 → 反色模式「关闭 → 开启 → 夜间自动（21:00–07:00）」；
   界面与面板整屏黑白反转，**封面 / 插图保留原始灰阶**；切换时整屏重刷。
10. **深色模式翻页表现**：
    - 不再使用“整帧扫描时钟”，避免字形脉冲变长、文字变粗；
    - 普通·快刷 / 普通·高清翻页保持单次差分输出，**不再每次闪白**（本版修复）；
    - 补黑（把黑底残留再压回黑）只保留在**水波纹**翻页之后，且只驱动纯白底像素，
      字形和抗锯齿边缘不动。
11. **主页刷新模式**：普通 / 快刷等原设置保留；书架、翻页的流畅度优化见下文。

## 三、字体与繁简

12. **繁简两态显示**：设置 → 显示 → 中文显示「全部繁体 / 全部简体」，界面与正文同时生效；
    只改显示，不改书文件、进度、书签。字库缺字时保留原字。
13. **繁体 TC 风格字形**：内建繁体 UI 字形改用 Noto Sans TC 风格轮廓（448 个）；
    简体模式仍用原简体字形。
14. **繁简按词选形**：在逐字表之上按后一个字选择正确繁体写法：
    发→髮/發、面→麵/面、干→乾/幹/干、只→隻/只、后→后/後、松→鬆/松、划→划/劃、
    准→准/準、台→颱/臺 等（例如 发型/发展、面条/面对、干净/干活/干涉、一只猫/只有）。
15. **自定义系统字体全局生效**：阅读工具栏及其二三级设置、设备设置子页、书架、键盘、
    USB 读卡页等都跟随设置里的系统字体；缺字自动回退内建字形。

## 四、书架、文件与传输

16. **书架搜索**：书架「管理」左边新增搜索按钮，输入中文/拼音/首字母/英文，
    按当前二级书架过滤，结果最近阅读优先；只过滤内存，不扫 TF 卡。
17. **书架封面加速**：进入书架不再先闪空书架；翻页/进入留汇合窗口一次画全；
    空闲预取相邻页封面到 SD fast 缓存（前后交替），点书先显示“正在打开…”再后台打开。
18. **书架点按反馈**：网格书架按下只重绘本格封面+层板，不再整页重绘，更跟手。
19. **文件管理 / 导入**：TF 卡浏览、WiFi 传书、热点传书、USB 读卡入口保留；
    USB 读卡页沿用自定义系统字体（USB 模式卸载 TF 卡后字库仍从 PSRAM 绘制）。

## 五、首页、统计与锁屏

20. **首页**：去掉每日闭环小圆环，保留分钟；今日阅读分钟移到头像右侧。
21. **阅读统计增强**：工具栏「阅读统计」→「阅读热力图」：本月日历热力图（按天阅读时长上灰阶）、
    本月合计/记录天数/最长连续/日均，并保留近 30 天趋势条。
22. **锁屏样式**：保留原有样式并新增「极简时钟」：两行显示（上行小时、下行分钟），
    白色底/反色下深底白字，不依赖卡上资源；每分钟局刷、每 20 分钟整屏全刷一次压残影。
23. **锁屏开机修复**：深睡唤醒后不再停在保留的时钟页无限等第二次按键；电源键唤醒后
    短暂停稳即恢复启动。分钟局刷只刷分钟行，刷新后留按键窗口；浅睡被拒绝时也检查按键。
    解锁提示按设置显示“单击/双击电源键解锁”。

## 六、系统与设置页

24. **设置页更新说明**：设置 → 升级和恢复 →「更新说明」离线显示版本与本版重点变化，
    已改为分页（每页 10 条、固定字号、底部页码，可滑动/点按翻页），不再溢出。
25. **配置备份与恢复**：保存与恢复配置、屏幕修复、BOOT 刷机、恢复出厂设置等原入口保留。
26. **OTA 升级**：支持 TF 卡本地升级包（`Pico-update.bin`），分区表与引导程序不变。

## 七、本版（P0–P3）修复与增强

**P0 开机与稳定**
30. 锁屏分钟刷新白框切到小时下缘：分钟局刷矩形上边界限制在小时行下方，不再白框盖住小时。
31. 时间锁屏开机困难加固：锁屏循环在入睡前、唤醒后、IOE 迟到事件三个位置都检查按键；
    深睡唤醒后不再等第二次按键，短暂稳定即恢复启动。
32. 偶发缺字：字形缓存分配失败时自动清缓存重试一次，避免单个字偶发消失。

**P1 深色翻页与性能**
33. 深色模式普通·快刷 / 普通·高清翻页恢复去残影：补黑改为短 DU 掩码驱动，只推纯白底，
    字形与 AA 边缘不动，不再整屏闪白。
34. 水波纹翻页后的补黑与动画衔接收紧：动画结束后立刻用同一遍快速补黑，间隔更短。
35. 普通·快刷翻页改用 DU 差分输出，牺牲少量文字抗锯齿换取更短刷新时间。

**P2 阅读交互与显示**
36. 从划线列表跳转后，阅读页底部出现「返回前阅读位置」按钮，点一下回到跳转前的位置。
37. 非全屏阅读的顶部状态栏改用设置里的系统字体（正文/页脚仍是阅读字体）。

**P3 小功能与耗电**
38. 设置 → 个性化功能新增「开机按键」：单击开机 / 双击开机可切换（与原有唤醒设置共用一个值）。
39. 锁屏签名、日期字号各 +4px。
40. 耗电优化：锁屏分钟局刷区域缩小、补黑改 DU 快路径，减少锁屏刷新与唤醒开销。

> P4「智能体实时校验代码和 Debug」属于开发流程建议，无法作为固件功能内置；
> 本定制流程每次改动都会执行 ESP-IDF 编译 + `validate.py` + 打包校验。

## 七之三十六、删除图片缩放功能

99. **删除图片缩放功能及全部连带内容**（用户要求）：
    - 移除阅读页的插图放大视图：双击放大、双指捏合缩放、单指拖动、双击退出全部去掉；
    - 连带移除：放大视图整帧渲染、缩放/平移状态、跟手 DU 刷新与 GL16 定稿逻辑、
      双击/单击仲裁（`s_image_tap_pending` 等）、旋转锚点与预览缓存的缩放判断；
    - 插图页恢复普通阅读手势：单击按分区翻页、双击中间切换全屏，与文字页一致；
    - 固件随之变小约 4.8KB（余量从 192,672 增至 195,744 字节）。

## 七之三十五、番茄钟/闹钟/待办/做个决定恢复底栏

98. **恢复番茄钟、闹钟、待办事项、做个决定的底栏显示**（用户要求）：这四个功能页重新
    显示底部导航栏，并恢复切页交互（点「特色」回入口页，其他栏正常切换应用）。四个
    小游戏页仍然不显示底栏（棋盘占满屏幕）；旧版右下角菜单把手保持关闭。

## 七之三十四、关闭特色功能的旧“功能”菜单把手

97. **修复特色功能二级页右下角仍弹出旧“功能”菜单**（真机反馈）：特色功能之前没有关闭
    旧版右下角菜单把手，任何子页（做个决定/番茄钟/闹钟/待办/小游戏）点右下角都会打开
    旧的「功能 Page 1/1」列表。现在特色功能整个应用（含入口页）都**关闭旧把手**：
    - 二级页右下角点击不再有任何反应；
    - 入口页右下角就是新底栏的「设置」，不会再被旧把手抢走；
    - 其他应用的旧把手行为不变。

## 七之三十三、图片双击放大 / 双指缩放 / 双击退出

96. **图片放大交互修正**（按用户确认的最终逻辑）：
    - **双击插图 = 放大**（直接放大到 2 倍进入放大视图）；第一下轻点先挂起 380ms，
      没有第二下就按普通翻页处理，所以“单击翻页”和“双击放大”不再互相抢；
    - 放大视图内**双指张开放大、合拢缩小**，**单指拖动平移**；
    - **双击退出**放大视图（单击不再退出，避免捏合后抬手误退；长按也可兜底退出）；
    - **跟手渲染**：缩放/拖动帧从 160ms 节流改为 **30ms 一帧**，并改用快速 DU 刷新；
      手指抬起后再补一次高质量 GL16 定稿清残影，缩放跟随明显更灵敏；
    - 提示文字改为「双指缩放 · 单指拖动 · 双击退出」。

## 七之三十二、特色功能子页不再显示底栏

95. **特色功能内所有程序进入后不显示底部工具栏**（用户要求）：番茄钟、闹钟、待办、
    做个决定以及四个小游戏都不再画底栏；底部工具栏位置整块留白，**点击该区域不会
    跳转到其他应用**（主循环也不再把它当切页输入）。入口页仍保留底栏；子页通过
    「长按中键」返回入口，再切到其他页面。

## 七之三十一、二级书架封面加载提速

94. **二级书架封面改为逐行显示**（真机反馈：进二级书架后封面加载很慢）：原来要等整页
    所有封面都解码完（整组就绪）才一起显示，二级书架切换时冷解码慢，只能盯着占位图。
    现在某一行的封面解码完成就立刻画那一行并只推该行区域，其余行继续占位、完成一行补
    一行；整页渲染也按“本行是否已解码”绘制。第一张封面出现时间从“等全部”缩短到
    “等第一张”。

## 七之三十、反色模式下的锁屏/关机壁纸

93. **反色模式下锁屏/关机壁纸保持正常显示**（真机反馈）：
    - 壁纸锁屏：壁纸先按正常灰阶画好，再按当前反色状态整帧预反相；扫描出口的反相会把
      它翻回原图，夜间反色时壁纸不再变成负片；
    - 锁屏壁纸缓存与深睡保留帧的缓存头都加入“当前是否反色”校验，昼夜切换后自动重绘，
      不会把旧极性的帧翻错；
    - 关机提示画面（“kiikoread 已关机”）同样保持白底黑字；
    - 其他锁屏样式（时钟/票根/拼贴/透明书封）仍是深色界面，只有照片类壁纸保持原色。

## 七之二十九、图片捏合缩放 / 字体预览提速 / 子页切换

90. **图片放大交互重做**：按新的操作逻辑——
    - **双击 = 切换全屏**，不再触发放大；
    - 阅读页上**双指向外张开 = 放大**、**双指向内合拢 = 缩小**（捏合即进入放大视图，
      从整图铺满开始，缩放范围 50%–400%）；
    - 放大视图内单指拖动平移、单击返回；提示文字同步改为「双指张开放大 · 合拢缩小 ·
      单指拖动 · 单击返回」。
    同时移除此前的“单击挂起 380ms”仲裁：插图页单击恢复立即翻页，双击中间仍是全屏。
91. **字体预览刷新提速**：字体选择页每轮批量生成最多 4 张预览卡、**合并成一次局部刷新**
    （此前每张卡都要单独局刷约 150ms，9 张卡光刷屏就 1 秒多），翻看字体样式明显更快。
92. **特色功能子页切应用**：从「做个决定/番茄/闹钟/待办」点底栏切到其他应用时整屏重绘
    一次，目标页不再继承子页的底栏/局部刷新基准（针对切到设置后画面异常做防御修复）。

## 七之二十八、插图双击放大 / 横屏锁屏壁纸

88. **修复插图页「双击放大」与「点一下翻下一页」冲突**：图上的第一次轻点不再被双击检测
    直接吞掉，而是**挂起 380ms**：
    - 380ms 内没有第二下 → 按正文分区正常翻页（上/下或左/右按设置）；
    - 380ms 内有第二下 → 进入插图放大，并**取消**这次翻页；
    - 滑动、长按、打开工具栏/面板、换页都会清掉挂起项，不会延迟到别处误翻。
89. **修复横屏时锁屏壁纸只显示一半**：锁屏壁纸原来固定画到 684×1216 的逻辑矩形，
    横屏旋转下 y≥684 的部分被裁掉。现在按**当前旋转后的整块画布**绘制，缓存头也按旋转
    后尺寸校验；配合锁屏入口统一方向，横屏/竖屏下壁纸都完整显示。

## 七之二十七、最终自查与全局流畅性优化

85. **全局流畅性优化**（按"当前所在界面"预热）：
    - **阅读页**：字体选择页改为预览遮罩缓存——打开首帧用当前字体占位，空闲时逐张换成
      各自字体的预览，**切换字体后的重绘不再重复装载字库**；字体目录每个目录一次开机只
      扫一次。阅读预取增加**第二块帧缓冲**：PSRAM 宽裕时提前排下下页，连续快翻两页零重
      排；内存紧张自动释放、退回单页预取。
    - **首页**：静止 1.2 秒后空闲预热——字体目录、设置页头像、**书架增量预热**（书目扫描
      + 首屏封面缓存），随后进书架/设置直接命中；触摸或切页立即让路。
    - **一级菜单/设置页**：静止 0.8 秒后分轮预热字体目录与图片列表；字体页入口不再现场
      扫卡；字体基准测试去掉重复的第二次整页刷屏。
86. **全量自查修复**（本轮审计）：
    - 特色功能入口页/子页**长按中键返回**恢复正常（入口回首页、子页回入口），子页点底栏
      「特色」也回入口；
    - 行距 **100% 可保存**（此前 100–109% 只重排不落盘）；
    - 竖屏时钟锁屏**跨整点/跨日**刷新小时行与日期（此前最多 19 分钟显示旧小时）；
    - 锁屏与 PIN 统一按**工厂竖屏**排版：阅读横屏/180° 后锁屏不再错位，PIN 键盘可正常点
      按；锁屏方向设置仍生效，退出后恢复原方向；
    - 深睡唤醒保留 **2 秒"双击开机"第二击窗口**，默认双击防误触仍有效；
    - 夜间自动反色不再整页重绘盖掉菜单/电源面板/快捷玻璃；PIN 下的时钟缓存方向键修正；
    - 贪吃蛇脏区补上**旧蛇头格**（消除每步残留的"白眼"拖影）；推屏期间捕获的轻点

## 七之二十五、横屏时钟上移 / 贪吃蛇按钮 / 书架加载

82. **贪吃蛇按钮更容易按**：原来是每走一步都把整块 640×640 棋盘做一次局部刷新，

## 七之二十三、水波纹·高清改为单次推屏

79. **「水波纹·高清」改为单次推屏**（真机反馈：画面抽象、字体卡一下、上一页突出约一秒、

## 七之十四、上下翻页方向修正

65. **「上下翻页」模式下点按翻页方向修正**（真机反馈）：主循环在推屏刷新期间会用后台
    采样器补记阅读页的轻点，而这条“补记”路径原来按**左右 1/3**判定翻页方向，没有采用

## 八、刷机指南

### 准备

- Windows 电脑、可传数据的 USB-C 线、设备电量充足（建议 50% 以上）。
- 安装 Python 3 与 esptool（任选其一）：
  - `pip install esptool`
  - 或使用你平时刷 ESP32-S3 的工具（如 Flash Download Tool），参数见下。
- 固件文件：
  - USB 完整包：`kiikoread-0.3.3-rc99-adaptive-USB/`（本目录）
  - TF 升级包：`standalone/Pico-update.bin`

### 方式 A：USB 线刷（推荐，保留分区与数据）

1. 打开本目录（含 `flash_args`、`bootloader.bin`、`partitions.bin`、
   `ota_data_initial.bin`、`firmware.bin`）。
2. 设备连接电脑，确认串口（例如 COM5；Windows 设备管理器可查）。
3. 在**本目录**执行（把 PORT 换成实际串口）：

   ```bat
   python -m esptool --chip esp32s3 --port PORT write-flash @flash_args
   ```

   或只刷应用镜像（不动引导程序/分区表）：

   ```bat
   python -m esptool --chip esp32s3 --port PORT write-flash 0x10000 firmware.bin
   ```

4. 刷完设备自动重启；首次启动较慢，屏幕会整屏刷新一次属正常。

> 如果 esptool 提示无法进入下载模式：先按住电源键/按一下复位，或按设备官方说明进入
> 下载模式后再执行；不要执行 `--erase-all`。

### 方式 B：TF 卡本地升级（不连线）

1. 把 `standalone/Pico-update.bin` 复制到 TF 卡根目录。
2. 把 TF 卡插回设备，进入 **设置 → 升级和恢复 → 系统升级 → 本地升级**，
   选择该文件并确认。
3. 升级完成后设备重启；引导程序与分区表不变，设置与阅读记录保留。

### 升级前后注意

- **不要全片擦除**（`--erase-all`），否则设置、书签、阅读记录都会丢失。
- 本包与官方分区表一致；若你之前刷过其他改分区固件，请先用官方完整包恢复分区。
- 刷机前建议在设备内 **设置 → 升级和恢复 → 保存与恢复** 备份到 TF 卡。
- 校验：Windows 可用 `certutil -hashfile firmware.bin SHA256` 与本包
  `SHA256SUMS.txt` 对照；TF 升级包与 `standalone` 同一 sha256。
- 回退官方版：用官方 USB 完整包按方式 A 刷回即可；分区/数据不受影响。

## 九、已知限制

- 繁简按词规则只看后一个字：公里/若干/关系/联系/北斗等需要前文的词仍可能按默认表。
- 内置繁体字形 448 个，极个别字（如「爲」）保留原字形；正文繁体仍依赖 TF 卡完整字库。
- 深色模式水波纹翻页后的补黑会多一次快速推进（普通·快刷/高清已不再补黑）。
- USB 读卡页的自定义字体依赖进入前预热：以后若新增 USB 页文案需同步加入预热列表；
  PSRAM 紧张时会自动回退内建字体。
- 首次打开没有缓存的封面仍需现场生成，之后翻页会命中缓存。
- 未做真机验证的能力（如特定 SD 卡、特定字体文件）以实机为准。
