页屿 PageIsle 0.3.3-rc99 定制固件（基于 kiikoread 0.3.3-rc99）
===================================================================

适用机型：RDP-G01-W 墨水屏（ESP32-S3 / 16MB flash）
分区表：与官方 USB 完整包完全一致，未改动
应用镜像：4,061,488 字节 -> ota_0 槽 4,194,304 字节，余量 132,816 字节，不溢出

页屿系统版本：1.15.13（2026-10-26，应用版本仍为上游 0.3.3-rc99）

本版修复（反色到页不自动全刷 / 左半边残影清不掉）：
  · 压黑补扫改 FULL 标定扫描 + 127 行预填，覆盖整屏（旧版 FAST 欠载只扫前半段，
    反色映射后正好是逻辑左半）；补上图文页、主页缺失的清理点。
  · 反色到页周期清理/手动整屏全刷改为「黑闪整屏清理」：瞬时压黑后重绘，彻底重推
    深色底残影，不出现白光；浅色模式不变。

页屿系统版本：1.15.12（2026-10-26，应用版本仍为上游 0.3.3-rc99）

本版修复（偶发整屏文字消失 + 坚果云内存门控/进度上限）：
  · 字形分配失败不再缓存空字形：清缓存重试、必要时内部内存兜底；整段 0 字形时自动
    换另一种字体重画；诊断写入 TF 卡根目录 pageisle_font_diag.log。
  · 坚果云联网任务前回收字形/表盘缓存并检查 PSRAM 余量；阅读进度快照上限 64→96。

页屿系统版本：1.15.11（2026-10-26，应用版本仍为上游 0.3.3-rc99）

本版修复（深色/反色白闪 + 小游戏分数叠影）：
  · 反色下整屏 GL16/GC16 不再驱动深色等灰对（物理黑底），普通/快刷/水波纹快刷/
    水波纹高清翻页、进书与整屏刷新不再整片白闪；浅色模式零回归。
  · 翻页末尾补黑改为只压物理黑底、不碰字形/抗锯齿/白字，且不再改写差分基准；
    进书/阅读周期清理/小游戏周期清理后追加压黑清理，黑底残影不再累积。
  · 防泛白在反色下不再整屏白推（改为深色等灰保持 + 压黑清理），不会每 5 分钟白闪。
  · 2048/贪吃蛇/五子棋/俄罗斯方块反色下周期清理改压黑清理 + 差分重绘，分数旧字迹
    不再叠层；浅色模式行为不变。

本版新增（页屿 PageIsle · 四个模块）：
  A. 坚果云同步：设置 →「连接与时间」→「坚果云同步」。填账号与应用密码、
     同步文件夹，点「测试连接」；「浏览云盘」可进子目录，列表只显示
     .md / .txt / .epub，点文件下载到书架「云同步」分类（带进度、可取消、
     重名先确认覆盖），下完自动上书架。
  B. Markdown 阅读：书架与文件页可直接打开 .md / .markdown。标题分级字号、
     粗体、斜体、高亮、列表、引用、代码块、分隔线与标准管道表格都按阅读排版
     渲染；章节标题自动生成目录；进度按「章节 + 章内偏移」保存，与 TXT 一致。
  C. Obsidian 互通：坚果云同步页 →「导出笔记」，把一本书的划线、笔记、标签
     生成 Obsidian 友好的 Markdown（带 front matter），PUT 回同步文件夹；
     vault 里的 .md 反过来用 A 的下载即可拉到设备阅读。
     （官方 Obsidian Sync 的私有协议不支持。）
  D. 手势配置：阅读工具栏 →「按键控制」→「手势设置」。双击中间 / 长按正文 /
     上滑 / 下滑 / 左滑 / 右滑 / 双指轻点 七个槽位逐个绑定动作
     （上一页 / 下一页 / 工具栏 / 全屏 / 返回主页 / 手动全刷 / 打开目录 / 划线 /
     不操作），另有「经典 / 上下翻页 / 单手 / 极简」四套推荐一键套用。
     「经典」与旧版行为逐条一致。
     长按正文的「划线 / 目录」开关也在这个「划线」页的右上角。

系统名改为「页屿 PageIsle」；固件包名、版本号与分区表保持 0.3.3-rc99 不变。

相对官方 rc99 只改动了应用层：
  1. 阅读设置第 7 项「竖排（从右到左）」替换为「自适应阅读方向」开关：
     打开后正文页由加速度计判定设备朝向，自动在竖屏 / 横屏（两个方向）间切换。
  2. 所有面板与菜单横屏可用：阅读设置、目录、书签、阅读统计、字体设置、排版、
     翻页模式、按键控制、字重、阅读线、背景选择等。
  3. 四档翻页效果：普通·快刷 / 普通·高清 / 水波纹·快刷 / 水波纹·高清。
  4. 设置 → 显示 → 反色模式：三态循环「关闭 → 开启 → 夜间自动（21:00–07:00）」，
     界面文字与面板整屏黑白反转，封面/插图保留原始灰阶；切换时整屏重刷。深色模式下
     阅读翻页改走整帧扫描时钟，减轻水波纹残影；自动全刷节奏仍完全跟随系统设置。
  5. 设置 → 显示 → 中文显示：全部繁体 / 全部简体（默认简体），点一下整体切换，
     界面与阅读正文同时生效。只改变显示，不改书文件、进度与书签；正文繁体需要
     TF 卡中的完整字库，当前字库缺字时保留原字。字级转换，个别多义字
     （发/髮、后/後）可能不够准确。
  6. 首页去掉每日闭环小圆环，保留分钟显示。
  7. 书架与触控响应优化：进入书架不再先闪一屏空书架；翻页/进入时给封面一小段
     汇合窗口，尽量一次画全，省掉“占位帧 + 补帧”的第二次整屏刷新；点书后先显示
     “正在打开…”再在后台打开；阅读预渲染按最近翻页方向准备，往回翻也有缓存。
  8. 划线：正文里长按会选中手指下的**当前这个字**（立即出现单字灰带），手指向前滑
     色带逐字增长、往回滑逐字收回；跨行、跨段自动接上，段落间隙也能连续选。松手保存；
     工具栏「划线」打开本书记录列表，可点行跳转、点右侧“删除”。记录跟着书保存
     （/sdcard/.readpico/highlight/ 或内置书的 /flash 同名目录），改字号/行距/繁简
     都不会移位。长按不再打开目录，目录请用工具栏「目录」。
  9. 图文混排的书：阅读时空闲会把下一页的插图提前解码到 PSRAM，翻到插图页直接显示，
     不用当场读卡解码，图文页翻页更跟手。
 10. 锁屏样式新增「极简时钟」：居中时分、下面当天日期、上面状态栏签名，
     白底黑字（反色模式下自动深底白字），不依赖卡上资源。锁屏后每分钟局刷时间，
     每 20 分钟整屏全刷一次压残影；期间只保留 PMU 时钟芯片与屏幕供电，触摸/
     加速度计/IOE 都停在最低功耗态（按键仍可唤醒）。
 11. 修复横屏阅读时章节第一页章名不显示：横屏改为预留一条紧凑章名横带并居中绘制；
     同时修复横屏章名重复一行：横屏重排也按紧凑带跳过正文里的标题字节。
 17. 修复长按划线只能选中一个字、无法拖动：长按本身回推一帧 ARED 会被主循环标记
     consumed，之前误把该标记当成取消拖动，导致第一帧就结束；现在拖动期间忽略它。
 18. 划线列表新增预设标签：每行右侧「标签」按钮点一下循环 无→重要→待读→疑问，
     标签随书 sidecar 保存（旧划线文件自动升级，标签默认无）。
 19. 极简时钟锁屏改为两行显示：上行小时、下行分钟（分钟更大），状态栏签名上移、
     日期下移；分钟局刷区域同时覆盖两行。
 20. 书架空闲时预取相邻页封面到 SD fast 缓存，翻到下一页直接命中，减少当场解码等待。
 21. 划线笔记：工具栏「划线」列表里**长按**一条记录打开笔记编辑器（复用阅读键盘），
     可写/改/清空一段短笔记；列表优先显示笔记（✎ 开头），笔记随书 sidecar 保存，
     旧划线文件自动升级（笔记默认空）。
 22. 书签列表新增预设标签：每行标签块点一下循环 无→重要→待读→疑问，随书书签记录保存；
     旧书签记录自动从 v2 升级到 v3（标签默认无）。
 23. 深色模式补黑只在**水波纹**翻页后触发：不再用整帧扫描时钟（会把字形脉冲拉长、字变粗），
     也不整块重驱动；只把纯白底像素（反色后的黑底）再驱动一次黑，字形与抗锯齿边缘完全不动，
     自动全刷节奏不变。普通·快刷 / 普通·高清翻页不再追加这遍驱动，避免深色底闪白。
 24. 繁简转换按词选形：在逐字表默认映射之上，增加后一个字上下文规则，
     发→髮/發（发型/发展）、面→麵/面（面条/面对）、干→乾/幹/干（干净/干活/干涉）、
     只→隻/只（一只猫/只有）、后→后/後（后妃/以后）、松→鬆/松、划→划/劃、准→准/準、
     台→颱/臺（台风）等；仍是显示层 1:1 换字，不改正文/偏移/进度。
 25. 修复书架「搜索」按钮点了会打开二级分类菜单（题头命中区覆盖到了按钮）；
     网格书架的按压反馈改为只重绘本格封面+层板，不再整页重绘，点按更跟手；
     相邻页封面预取改为前后交替，来回翻书架都能命中缓存。
 26. 长按正文里**已经划线的句子**可直接删除整段划线（提示“已删除划线”），
     不再进入拖动；长按未划线处仍是新建/拖动划线。
 27. 划线工具栏列表行排版修正：章节名与右侧「第 N 页/章 N」分别预留宽度并裁在
     行卡片内，长章节名不再压到页码、不越过边框。
 28. USB 读卡页改用设置里的自定义系统字体：USB 模式卸载 TF 卡时不再强制回退内建字体，
     字库继续留在 PSRAM，并在进入前把本页/状态栏用到的字形预热进缓存。
 29. 锁屏两行时钟行距收紧：不再用固定 37%/61% 两行，改为“两行数字字面高度 + 小空隙”
     计算中心距，整组时间居中在屏幕 47% 处。
 30. 修复时间锁屏“开不了机/开机困难”：深睡唤醒后不再在保留的时钟页上无限等第二次按键，
     电源键唤醒后短暂停稳即恢复启动；分钟局刷只刷分钟行、刷新后留 400ms 按键窗口，
     浅睡被拒绝时也继续检查按键；解锁提示按设置显示“单击/双击电源键解锁”。
 31. 设置→升级和恢复→更新说明改为分页：每页 10 条、固定字号，底部「‹ 1/3 ›」页码，
     左右点按页码或上下滑动翻页，长列表不再溢出卡片。
 32. 修复深色模式下普通·快刷 / 普通·高清翻页每次都闪白一次：普通翻页不再追加补黑驱动，
     恢复单次差分输出；补黑只保留在水波纹翻页之后。
 33. P0 锁屏稳定性：分钟局刷矩形不再压到小时行（修复开机后白框切掉小时下缘）；锁屏循环
     在入睡前、唤醒后、迟到事件三个位置都检查按键；深睡唤醒不再等第二次按键；
     开机/唤醒更可靠。
 34. P0 偶发缺字：字形缓存分配失败时清缓存重试一次，避免单个字偶发消失。
 35. P1 深色去残影：普通·快刷 / 普通·高清翻页重新接入补黑，但改为短 DU 掩码驱动
     （只推纯白底，字形与 AA 边缘不动），不再整屏闪白；水波纹翻页后同一遍快速补黑，
     与动画的间隔更短。
 36. P1 快刷提速：普通·快刷翻页改用 DU 差分输出，牺牲少量文字抗锯齿换取更短刷新。
 37. P2 交互/显示：划线列表跳转后阅读页底部出现「返回前阅读位置」按钮，一键回到跳转前
     位置；非全屏阅读的顶部状态栏改用设置里的系统字体。
 38. P3 小功能：设置→个性化功能新增「开机按键」单击/双击切换；锁屏签名、日期字号各 +4px；
     锁屏分钟局刷区域缩小、补黑改 DU 快路径，减少唤醒与刷新耗电。
 39. 普通·快刷残影修复：撤回 DU 翻页，恢复 GL16 差分擦除（DU 残留会整页叠影）；
     深色补黑仍为掩码 DU，只推纯白底、字形不动。
 40. 阅读统计新增「章节跳转」：面板里左右 − / + 在当前章节内翻一页，中间显示「x / x 页」，
     竖屏/横屏分别排版，− / + 与页码都可点；关闭面板回到跳转后的页面。
 41. 主页时钟样式切换预览优化：从整块 812px 刷新缩小到“表盘 + 名称/说明/圆点”区域，
     并走短 DU 快路径，连续切换更跟手。
 42. 插图放大：阅读页双击插图进入放大视图（默认 2 倍），单指拖动平移，双指上下拖动缩放
     （1.2–4 倍），再次双击 / 单击 / 长按回到原阅读页；横竖屏适配，反色下保留原灰阶。
 43. 底部导航改为 5 栏：首页 / 特色功能 / 书架 / 文件 / 设置，书架居中；
     特色功能栏位图标由固件自绘，不依赖卡上资源。
 44. 特色功能入口页：2×4 圆角卡片铺满内容区，8 个入口
     （贪吃蛇 / 俄罗斯方块 / 2048 / 五子棋 / 番茄时钟 / 闹钟 / 做个决定 / 待办）
     与图标均由固件绘制；长按硬件中键从子页返回入口页、从入口页返回首页。
      本里程碑先完成导航、入口与退出；各功能/游戏内容在后续里程碑逐个实装。
 45. 插图缩放逻辑修正：双击插图进入放大后，双指分开 = 放大、
     双指合拢 = 缩小（按两指距离比例）；单指拖动 = 平移照片；
     再次双击返回原阅读页。
 46. 翻页抢输入：水波纹与主页翻页推屏期间后台继续采样触摸，
     翻页后立即消化底栏点击；阅读页中间两侧的快速点击也会排队执行下一次翻页，
     不再要求等屏幕刷完才能继续点。
 50. 首页右下模块三态：日历 → 待办 → 本月统计 → 日历，长按该模块循环切换并记住选择；
     待办列表可点句标记完成（NVS 保存）；本月统计显示合计/记录/连续/日均
     与每日趋势条，元素分开排版。
 51. 特色功能“做个决定”内容实现：投币按钮、正/反结果与翻面过渡；其余游戏与工具内容在后续批次接入。
 52. 特色功能新增「番茄时钟」：25 / 5 分钟预设一键切换，开始 / 暂停 / 继续 / 重置；
     计时中每秒局部刷新倒计时，到点整页提醒并短鸣，点屏或按任意键停止。
 53. 特色功能新增「周闹钟」：周一到周日任意多选，时/分可调（5 分钟步进 + 1 分钟微调），
     启用后保存到 NVS；到点整页提醒并短鸣。锁屏等待中按设定时间唤醒；自动深睡时
     通过 PMU 的 RTC 闹钟唤醒主机后再响铃，触摸或任意键停止。
     （彻底关机不会自动开机；长时间深睡的到点精度受 PMU 内部 RTC 影响。）
 54. 特色功能「2048」：4×4 棋盘滑动合并，分数/最高分与重新开始；合并出 2048 播胜利短旋律，
     无路可走播失败短旋律。
 55. 特色功能「贪吃蛇」：20×20 棋盘，棋盘上滑动转向，开始/暂停/重新开始；
     吃到食物增长计分，每 20 步整屏整理一次残影；撞墙/撞自身播失败短旋律。
 56. 特色功能「俄罗斯方块」：10×20 棋盘，七种方块，左移/右移/旋转/软降/硬降、暂停/重开；
     消行按 1/2/3/4 行计分并逐级提速；消满 10 行胜利、堆顶失败均有短旋律。
 57. 特色功能「五子棋」：15×15 人机对战，玩家执黑先手；简单/困难两档 AI
     （困难档先成五、再堵五、再按连子形状评分），支持悔棋、重新开始与胜负提示/短旋律。
