## 〇、页屿 PageIsle 本版新增（四个模块）

### 0.1 坚果云同步（WebDAV）

- 设置 →「连接与时间」→ 新增第 4 行「坚果云同步」，进入独立同步页；页面不进主菜单，
  返回键/右滑回到设置主页。
- 账号配置：坚果云账号（邮箱）+ **应用密码**（不是登录密码），可填同步文件夹路径
  （相对坚果云根目录，如 `/Obsidian/Books`）；密码在 NVS 里做可逆混淆存放，
  且**不进入设置备份**（避免明文密码随备份文件外泄）。
- 「测试连接」：先联网校时（TLS 证书校验需要正确时间），PROPFIND 根目录成功即提示连接成功。
- 「浏览云盘」：PROPFIND Depth:1 列目录，**允许逐层进子目录**（面包屑可回上级）；
  `.md / .markdown / .txt / .epub` 才显示为可下载文件，其它文件隐藏并计数；
  每行显示名称、大小、修改时间；目录项上限 256，超过提示用子目录缩小范围。
- 下载：GET 流式写入 `<命名>.part` 再改名，**进度条 + 取消**；目标重名先确认覆盖；
  空间不足、无网络、认证失败、目录不存在、超时都有中文提示。
- 落盘位置：书架根目录下的新二级目录 **`云同步`**（`/sdcard/books/云同步/`，
  内置存储时为 `/flash/books/云同步/`）；书架是递归扫描，因此下载完自动出现，
  并且书架分类里会多出「云同步」一级分类。下载完成调用书架重扫，无需手动刷新。

### 0.2 Markdown 离线阅读

- 书架与文件管理都能识别 `.md / .markdown`；打开后与 TXT/EPUB 共用阅读面板、
  工具栏、目录、书签、划线、阅读统计与逐书进度。
- 解析与排版：ATX 标题 H1–H6（标题分级字号）、段落、无序/有序列表、引用、围栏代码块、
  分隔线；行内 `**粗体**`、`*斜体*`、`==高亮==`、`` `行内代码` ``、`[文字](链接)`、
  `![alt](图片)`（显示为 `[图] alt`）、`\` 转义；嵌套样式按位组合。
- 标准管道表格：识别表头 + `|---|:--:|` 对齐行，按当前正文宽/字号/字距计算列宽，
  单元格内自动折行，用空格补齐到列边界（像素级对齐），竖线分隔、行尾不留空格；
  表格总宽上限 560 px，避免旋转/横屏切回竖屏时被二次折行。
- 自动目录：章节标题直接生成目录（一章一项）；纯 Markdown 无标题时按 48 KB
  段落在空行处切章，同样可以翻目录。
- 逐书进度：仍按「章节号 + 章内输出文本偏移」保存，与 TXT 完全同一套 NVS 记录；
  字号/边距/行距/段距/字距/旋转/切换系统字体后会自动重新解析当前章，
  让表格与排版按新指标重新成形（解析失败则保留旧排版，不会崩）。
- 内存与上限：单章源 96 KB、输出 512 KB、目录 2048 章；表格行 256 行、16 列。

### 0.3 Obsidian 互通

- 拉取：坚果云同步页浏览 vault 目录（可进子目录），把 `.md` 下载到设备阅读，
  即“把 Obsidian 库当书库用”；增量由手动浏览 + 修改时间列判断。
- 导出：同步页 →「导出笔记」，列出有划线/笔记的书（来自 `book_progress_list()`），
  选中后把该书的划线摘录、笔记、标签、章节位置生成 Obsidian 友好的 Markdown：
  `---` front matter（source / exported / device）+ `# 书名 笔记` + `## 划线` +
  `> 摘录` + `- 笔记：…` + `- 位置：第 N 章 · 标签`，
  写到 TF 卡临时文件后 **PUT** 到同步文件夹，文件名 `<书名>-notes-YYYYMMDD-HHMM.md`。
- 明确不做：官方 Obsidian Sync 的私有协议（E2E 加密），只走坚果云 WebDAV。

### 0.9 修复：退出阅读后的界面残影（回退延迟补白）

- **问题**：上一版把补白放到推屏后 ≈8 ms 的 `on_tick` 里执行，真机上「退出阅读页后，
  二三级界面与时钟锁屏残影都很严重」。
- **原因**：补白的第一步会把 back 基准里「纯白底」像素标成 0，再靠一次差分把它驱回白。
  放在 `on_tick` 里执行时，这一遍可能和主页面的转场状态（`main_before_update` 拦截、
  面板/锁屏切换）交错：被拦截或提前切换时基准停在「已标黑」的状态，之后的差分屏
  （设置子页、时钟锁屏）就会按错误基准刷新，旧内容擦不干净→残影。
- **修复**：回退到 **翻页 `present()` 内立即补白**（深色补黑）的已验证顺序——补扫和翻页
  在同一次 present 内完成，不存在与页面切换交错的窗口；其余（-O3 满配、清残影波形、
  8 帧 FOLLOW、周期全刷）不变。
- 镜像 4,037,648 B，ota_0 余量 156,656 B。

### 0.8 清残影：原版 rc99 翻页算法 + 延迟补白

### 0.6 翻页清残影（白天补白 / 深色补黑，最早验证版）

- 白天模式阅读时，页面两侧与行间空白在差分刷新里永远不参与驱动，上一页字形抗锯齿的
  残留会越积越深（用户反映两侧残影明显）；深色模式对应的是黑底残留。
- 做法（最终保留）：每次文字翻页后补一遍「地面定稿」——把 back 基准上「front 为纯白」的
  底色像素标成 0，再走一遍 8 帧 FOLLOW/DU 差分，只对纯白底产生「往白推」（白天）或
  「往黑推」（深色）；字形与抗锯齿边 back==front，不进差分，字不会变细或变粗。
- 四种翻页（普通·快刷 / 普通·高清 / 水波纹·快刷 / 水波纹·高清）共用；只在纯文字页触发
  （面板、插图页、自定义阅读背景不触发），与自动全刷节奏无关。
- 版本演进（保留备查）：曾试过把这遍并进翻页扫描——真机上「刷新后文字几乎消失」，已回退；
  也试过 4 帧短补表——更快但力度弱；用户确认改回最早这一版（8 帧 FOLLOW）。

### 0.5 已知限制（本版）

- 系统名为「页屿 PageIsle」，但固件版本号/包名/分区表仍是 0.3.3-rc99，OTA 与旧包同级。
- USB/WiFi 传书入口仍只接收 TXT/EPUB（限制在传输组件与网页里，未改）；
  Markdown 请走坚果云同步或读卡拷入书架目录。
- 内置字体没有 `─│` 等制表符号，表格分隔线改用 ASCII `|`、分隔线用长破折号，
  缺字形字体下不会出豆腐块。
- 本版未做真机验证：上述功能只经过 ESP-IDF v6.1 编译、`validate.py`、打包与
  静态审核；真机上的刷新观感、TLS 联调、双指/滑动阈值需实测确认。

## 七之十四、上下翻页方向修正

65. **「上下翻页」模式下点按翻页方向修正**（真机反馈）：主循环在推屏刷新期间会用后台

## 八、刷机指南

### 准备

- Windows 电脑、可传数据的 USB-C 线、设备电量充足（建议 50% 以上）。
- 安装 Python 3 与 esptool（任选其一）：
  - `pip install esptool`
  - 或使用你平时刷 ESP32-S3 的工具（如 Flash Download Tool），参数见下。
- 固件文件：
  - USB 完整包：`kiikoread-0.3.3-rc99-adaptive-USB/`（本目录）
  - TF 升级包：`standalone/Pico-update.bin`

### 方式 A：USB 线刷（推荐，保留分区与数据）

1. 打开本目录（含 `flash_args`、`bootloader.bin`、`partitions.bin`、
   `ota_data_initial.bin`、`firmware.bin`）。
2. 设备连接电脑，确认串口（例如 COM5；Windows 设备管理器可查）。
3. 在**本目录**执行（把 PORT 换成实际串口）：

   ```bat
   python -m esptool --chip esp32s3 --port PORT write-flash @flash_args
   ```

   或只刷应用镜像（不动引导程序/分区表）：

   ```bat
   python -m esptool --chip esp32s3 --port PORT write-flash 0x10000 firmware.bin
   ```

4. 刷完设备自动重启；首次启动较慢，屏幕会整屏刷新一次属正常。

> 如果 esptool 提示无法进入下载模式：先按住电源键/按一下复位，或按设备官方说明进入
> 下载模式后再执行；不要执行 `--erase-all`。

### 方式 B：TF 卡本地升级（不连线）

1. 把 `standalone/Pico-update.bin` 复制到 TF 卡根目录。
2. 把 TF 卡插回设备，进入 **设置 → 升级和恢复 → 系统升级 → 本地升级**，
   选择该文件并确认。
3. 升级完成后设备重启；引导程序与分区表不变，设置与阅读记录保留。

### 升级前后注意

- **不要全片擦除**（`--erase-all`），否则设置、书签、阅读记录都会丢失。
- 本包与官方分区表一致；若你之前刷过其他改分区固件，请先用官方完整包恢复分区。
- 刷机前建议在设备内 **设置 → 升级和恢复 → 保存与恢复** 备份到 TF 卡。
- 校验：Windows 可用 `certutil -hashfile firmware.bin SHA256` 与本包
  `SHA256SUMS.txt` 对照；TF 升级包与 `standalone` 同一 sha256。
- 回退官方版：用官方 USB 完整包按方式 A 刷回即可；分区/数据不受影响。

## 九、已知限制

- 繁简按词规则只看后一个字：公里/若干/关系/联系/北斗等需要前文的词仍可能按默认表。
- 内置繁体字形 448 个，极个别字（如「爲」）保留原字形；正文繁体仍依赖 TF 卡完整字库。
- 深色模式水波纹翻页后的补黑会多一次快速推进（普通·快刷/高清已不再补黑）。
- USB 读卡页的自定义字体依赖进入前预热：以后若新增 USB 页文案需同步加入预热列表；
  PSRAM 紧张时会自动回退内建字体。
- 首次打开没有缓存的封面仍需现场生成，之后翻页会命中缓存。
- 未做真机验证的能力（如特定 SD 卡、特定字体文件）以实机为准。
