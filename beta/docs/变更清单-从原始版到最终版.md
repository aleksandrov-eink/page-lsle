## 0. 口径与版本信息

- **原始基线**：上游 `kiikoread 0.3.3-rc99`（RDP-G01-W / ESP32-S3 电子墨水屏，
  逻辑分辨率 684×1216，横屏 1216×684）。
- **最终版本**：0.3.3-rc99 定制版（系统名 **页屿 PageIsle**）；应用镜像 **4,004,752 字节**，
  ota_0 分区余量 **189,552 字节**，sha256 `7e6d4187ba3dc6fa14da9bfc72342a43bb59defba393c24a2b30378733bb18ad`。
- **口径说明**：本机未保留原始基线的 git 快照，以下清单依据包内《改版日志与刷机指南》
  的 99 条记录、最终源码目录与交付记录整理；「新增 / 删除 / 优化 / 修复」按改动性质分类，
  部分早期条目属于前几轮已交付内容，收尾版本全部包含。
- **验证状态**：ESP-IDF v6.1 编译通过、`validate.py` VALID、打包与 SHA256SUMS 校验通过；
  **未做真机验证**。

### 1.1 阅读与排版

- **自适应阅读方向**：原「竖排（从右到左）」开关替换为「自适应阅读方向」，由加速度计判定
  设备朝向，自动在竖屏 / 横屏两方向间切换；全部面板、菜单、工具栏都做了横屏适配。
- **四档翻页效果**：普通·快刷 / 普通·高清 / 水波纹·快刷 / 水波纹·高清，可分别选择。
- **字级划线**：正文长按只选中手指下的当前字，前滑逐字增长、后滑逐字收回，跨行跨段自动
  接上；划线按书 sidecar 保存，改字号 / 行距 / 繁简不漂移。
- **划线列表与笔记**：工具栏「划线」可查看本书记录、点行跳转、分页、删除；支持预设标签
  （无→重要→待读→疑问），长按一条可写 / 改 / 清空笔记；长按正文中已划线句子可直接删除。
- **书签标签**：书签列表每行标签块循环 无→重要→待读→疑问，随书记录保存。
- **返回前阅读位置**：从划线 / 目录跳转后，阅读页底部出现「返回前阅读位置」按钮。
- **章节内自由跳转**：阅读统计面板新增「章节跳转」卡，− / + 翻页并显示「当前页 / 本章总页数」。
- **阅读热力图**：本月日历热力图（按天阅读时长上灰阶）+ 合计 / 记录天数 / 最长连续 / 日均，
  并保留近 30 天趋势条。
- **图文书插图预读**：空闲时把下一页插图提前解码进 PSRAM，翻到插图页直接显示。
- **连续字号滑杆**：阅读字号 1px 步进；字重、行距、缩进、阅读线等原设置保留。
- **行距更紧**：滑杆范围从 110%–150% 扩展到 **100%–150%**，且 100% 可正常保存。
- **繁简两态 + TC 字形 + 按词选形**：界面与正文同时简体 / 繁体；内建 448 个繁体 UI 字形；
  逐字映射之上增加上下文规则（发→髮/發、面→麵/面、干→乾/幹/干、只→隻/只、后→后/後、
  松→鬆/松、划→划/劃、准→准/準、台→颱/臺 等）。
- **自定义系统字体全局生效**：阅读工具栏及二三级设置、设备设置子页、书架、键盘、USB 读卡页
  都跟随系统字体；缺字自动回退内建字形。
- **书架搜索**：输入中文 / 拼音 / 首字母 / 英文，按当前二级书架过滤，最近阅读优先，只过滤内存。
- **字体数量上限 24 → 50**：阅读字体选择页（每页 9 款、上下滑动）与设置里的系统字体页都
  能列到第 50 个。
- **划线功能开关 + 长按延时**：阅读设置标题栏「长按：划线 / 长按：目录」开关；划线长按
  等待从约 500ms 提高到约 720ms，减少误触。

### 1.2 显示、刷新与反色

- **反色模式三态**：关闭 → 开启 → 夜间自动（21:00–07:00）；界面与面板整屏反转，
  封面 / 插图保留原始灰阶；夜间自动会按时间边界重刷。
- **四档翻页波形与「水波纹」揭页引擎接入**：水波纹翻页 + 校准灰阶表；「水波纹·高清」

- **深色模式补黑策略**：只在水波纹翻页后补黑，且只驱动纯白底像素，字形与 AA 边缘不动；

- **夜间反色加固**：时间来源与状态栏一致（系统时钟无效时退回 PMU RTC）、5 秒核对、推屏前

- **主页刷新模式**：普通 / 快刷等原设置保留，并与书架、翻页流畅度优化联动。

## 3. 优化的内容（更快、更顺、更稳、更顺手）

### 3.1 刷新与显示

- 四档翻页效果 + 水波纹揭页；水波纹·高清从“两遍推屏”变“单次推屏”，无上一页残留、无停顿。
- 深色模式：补黑只推纯白底、只用短 DU 掩码，字形与抗锯齿边缘不动；普通翻页不再闪白。
- 主页时钟切换预览、锁屏分钟局的刷新区域都缩小；锁屏补黑改 DU 快路径，降低唤醒开销。
- 贪吃蛇每步只推变化格；游戏按钮点击在推屏期间队列化重放；游戏页整屏刷新不再冻结旧底栏。
- 读卡 / 主页 / 设置等页面切换的整页刷新与局部刷新路径统一，跨应用清理旧基准。

### 3.2 阅读性能

- 字体选择页预览遮罩缓存：首帧占位、空闲逐张换本字体预览；每轮批量生成最多 4 张、
  合并一次局部刷新；切换字体后的重绘零装载；字体目录每个目录开机只扫一次。
- 第二块预渲染帧缓冲：PSRAM 宽裕时预排下下页，连续快翻两页零重排；内存紧张自动降级释放。
- 字形缓存 320KB → 448KB；字形分配失败自动清缓存重试，避免偶发缺字。
- 插图预读、阅读进度缓存、旋转锚点、预取页面缓存、预绘任务优先级调度。

### 3.3 首页 / 书架 / 设置性能

- 首页 idle 1.2s：字体目录、设置头像、书架增量预热（扫描 + 首屏封面）。
- 设置页 idle 0.8s：字体目录、图片列表分轮预热；字体页入口不再现场扫卡。
- 二级书架封面逐行解码显示；相邻页封面预取；书架进度一次遍历读入 512 条缓存。
- 书架首帧一次性汇合、点书先反馈再后台打开、网格按下只重绘本格。

### 3.4 交互与视觉

- 5 栏底部导航、特色功能图标线宽 / 尺寸统一、入口页 2×4 卡片。
- 自适应方向 + 180° 倒置竖屏触摸映射 + 旋转锚点（横竖切换不丢进度）。
- 「上下翻页」模式下刷新期补点与正常点按同一套分区；快速连点方向一致、不丢点。
- 行距 100%–150%、字体上限 50、划线开关与长按延时、首页模块锁定、锁屏方向与字号。
- 游戏近全屏：2048 棋盘 636×636、俄罗斯方块 360×720、五子棋 616×616、贪吃蛇 640×640
  + D-pad；四款游戏无底栏，四个实用页有底栏。

### 3.5 稳定性与工程

- 全量自查（两份只读审计 + 各模块自查）：未发现 P0，P1 全部修复，P2 择要修复。
