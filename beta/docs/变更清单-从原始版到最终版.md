### 1.0 页屿 PageIsle 四模块（本轮新增）

- **坚果云同步（WebDAV）**：设置 →「连接与时间」→「坚果云同步」。账号 + 应用密码 +
  同步文件夹，`PROPFIND Depth:1` 列目录并**允许逐层进子目录**；只列 `.md / .txt / .epub`，
  显示名称/大小/修改时间；流式下载（`.part` → 改名）带进度与取消，重名先确认覆盖；
  目标落盘为书架根下新二级目录 `云同步/`，下完自动上书架；密码混淆存 NVS 且不进设置备份。
  新增 `main/net/webdav_client.c/.h`（Basic Auth、`esp_crt_bundle`、最小 XML 子集解析、
  RFC1123 时间、percent 解码）与 `main/apps/app_cloud.c/.h`（账号 / 浏览 / 下载 / 导出四视图，
  独立 FreeRTOS 任务 + 状态快照，联网与校时复用 `read_pico_transfer_*`）。
- **Markdown 离线阅读**：书架与文件管理识别 `.md / .markdown`，与 TXT/EPUB 共用面板、
  目录、书签、划线、统计与逐书进度。解析 ATX 标题 H1–H6（分级字号）、段落、列表、引用、
  围栏代码块、分隔线；行内粗体 / 斜体 / 高亮 / 行内代码 / 链接 / 图片占位 / 转义；
  标准管道表格按正文宽/字号/字距算列宽、单元格内折行、空格补齐到像素级列边界
  （列宽上限 560 px）；章节标题自动生成目录；改字号/字距/旋转/换字体后自动重新解析当前章。
  新增 `main/book/book_md.c/.h`；`book_source` 增加 `BOOK_KIND_MARKDOWN = 2`；
  `book_layout.c` 增加行内样式绘制（粗体=可变字重、斜体=覆盖率遮罩横向剪切、高亮=灰带）。
- **Obsidian 互通**：同步页浏览 vault 目录下载 md（拉取）；「导出笔记」把划线/笔记/标签生成
  Obsidian 友好 md（front matter + `## 划线` + `> 摘录` + 笔记 + 位置/标签）用 PUT 推回同步
  文件夹。不做官方 Obsidian Sync 私有协议。
- **手势配置**：阅读工具栏 →「按键控制」→「手势设置」。七个槽位（双击中间 / 长按正文 /
  上滑 / 下滑 / 左滑 / 右滑 / 双指轻点）× 九种动作；四套预设（经典 / 上下翻页 / 单手 /
  极简）+ 全自定义，逐槽位存 NVS。双指轻点由阅读页读原始触摸快照识别（600 ms / 24 px）；
  经典预设与旧版行为在「四方向 × 上下翻页 × 竖排」16 种组合下逐格一致。
- **阅读设置瘦身**：长按正文的「划线 / 目录」开关从「阅读设置」移到底部工具栏 →
  「划线」页右上角，和划线列表放在一起，阅读设置页少一行。
- **流畅性满配（+270 KB）**：main/自研组件/托管编解码器/IDF 存储显示组件全部 -O3，
  热点像素排版文件循环展开；字形缓存 1.5 MB；两页预渲染常开；热点日志静音；I-cache 32 KB。
- **清残影：翻页内立即补白**（深色补黑，只推纯白底、字形不动）：补扫与翻页同一次完成，
  不与页面/面板切换交错，退出阅读后的菜单与锁屏不再带正文残影。
- **启动画面统一 + 固件瘦身**：删除「准备资源」开机图（`loading_4bpp.bin`，415,872 字节内嵌
  4bpp 整屏位图），冷启动与所有深睡唤醒统一只显示小锁界面；镜像与余量数字见第 0 节。

### 1.0z 页屿系统 1.15.9（高清水波纹提速 + 反色白闪修复）

- 用户反馈：①水波纹·高清翻页太慢，要求在不损失现有抗锯齿的前提下提速；②深色（反色）模式下

- **提速**：条带从最多 32 带降回 8 带，节拍从 12ms 压到 11090us（与扫描帧标定一致，不再补等）：
  32 带 68 拍 ≈0.82s → 8 带 44 拍 ≈0.49s，和「水波纹·快刷」同速。条带数只决定揭页前沿的

  所以抗锯齿中灰的脉宽与质量不变，只是前沿从 32 级渐变回到 8 级台阶；仍单次推屏、结束提交基准。
- **反色白闪**：反色模式下整页背景在物理上是深色，而 GL16 表对等灰对（15→15 白推、0→0 擦推）
  有驱动；旧逻辑把整片背景也按等灰对重推，于是深色背景被推亮再压回，形成揭页中间明显的白闪。

- **书架搜索**：输入中文 / 拼音 / 首字母 / 英文，按当前二级书架过滤，最近阅读优先，只过滤内存。
- **字体数量上限 24 → 50**：阅读字体选择页（每页 9 款、上下滑动）与设置里的系统字体页都
  能列到第 50 个。
- **划线功能开关 + 长按延时**：阅读设置标题栏「长按：划线 / 长按：目录」开关；划线长按
  等待从约 500ms 提高到约 720ms，减少误触。

### 1.2 显示、刷新与反色

- **反色模式三态**：关闭 → 开启 → 夜间自动（21:00–07:00）；界面与面板整屏反转，
  封面 / 插图保留原始灰阶；夜间自动会按时间边界重刷。
- **四档翻页波形与「水波纹」揭页引擎接入**：水波纹翻页 + 校准灰阶表；「水波纹·高清」
  最终改为**单次快速扫描推屏**。
- **深色模式补黑策略**：只在水波纹翻页后补黑，且只驱动纯白底像素，字形与 AA 边缘不动；
  普通翻页不再追加补黑。
- **夜间反色加固**：时间来源与状态栏一致（系统时钟无效时退回 PMU RTC）、5 秒核对、推屏前
  再核对、手动改时间立即重核、锁屏按当前昼夜建立。
- **主页刷新模式**：普通 / 快刷等原设置保留，并与书架、翻页流畅度优化联动。

### 1.3 锁屏、电源与开机

- **极简时钟锁屏**：居中时分、下面日期、上面状态栏签名；每分钟局刷、每 20 分钟整屏全刷压残影。
- **时钟锁屏方向**：新增「时钟锁屏方向」竖屏 / 横屏开关，两个入口可切换；横屏为真实整屏旋转，
  解锁后恢复进入锁屏前的方向。
- **锁屏字号加大并适配横屏**：签名 / 日期各 +6px，时、分大字 +8px；横屏按画布宽度取字号、
  时间单行显示、时分行上移到画布 46%。
- **开机按键单击 / 双击切换**：设置 → 个性化功能新增，与原有唤醒设置共用同一个值。
- **深睡唤醒双击开机保留第二击窗口**：最多 2 秒等待第二击，避免误触直接进系统；同时修复
  “开机困难”（不再在保留的锁屏页无限等第二次按键）。
- **配置备份与恢复、屏幕修复、BOOT 刷机、恢复出厂、OTA（TF 卡本地升级）**：保留并提供
  更新说明分页（每页 10 条、页码可翻）。
- **旧版右下角「功能」菜单把手**：在特色功能应用内整体关闭（其他应用行为不变）。

### 1.4 书架、文件与传输

- **书架封面加速**：进入书架不再先闪空书架；翻页 / 进入留一次性汇合窗口画全；空闲预取
  相邻页封面到 SD fast 缓存；点书先显示「正在打开…」再后台打开。
- **书架点按反馈**：网格书架按下只重绘本格封面 + 层板，不再整页重绘。
- **书架进度缓存**：重扫前一次性把全部阅读进度读进内存（512 条 PSRAM 缓存），之后逐本查表。
- **二级书架封面逐行显示**：解码好一本显示一本，不再等整页封面全部解码。
- **文件管理 / 导入 / WiFi 传书 / 热点传书 / USB 读卡**：原入口保留，USB 读卡页沿用自定义
  系统字体（卸载 TF 卡后字库仍从 PSRAM 绘制）。

### 1.5 首页与统计

- **阅读统计增强**：热力图、本月合计、记录天数、最长连续、日均、近 30 天趋势。
- **主页时钟样式切换预览优化**：预览只刷新表盘 + 名称/说明/圆点区域。
- **去掉首页每日闭环小圆环**，今日阅读分钟移到头像右侧（删除项，见第 2 节）。
