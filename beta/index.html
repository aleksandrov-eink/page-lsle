浏览器一键刷机（USB 有线）

用 电脑版 Chrome / Edge，数据线连接设备即可。无需安装驱动工具，不占用本地文件。

⚠ 刷机确认框里不要勾选 “Erase device” 点刷机后会出现一个英文确认框（Erase device）：保持不勾选，直接点 Next。 勾选它会整片擦除 Flash——设置、阅读记录、阅读统计全部清零（这一版早期页面就踩过这个坑）。
当前浏览器不支持 Web Serial，请改用电脑版 Chrome 或 Edge（89 及以上）。 页面必须通过 HTTPS 或 localhost 打开才能刷机。

刷入后设备会自动重启。若没有自动重启，长按电源键一次即可。请先关闭占用该串口的程序（如 idf.py monitor、串口助手）。

  • 电脑版 Chrome / Edge 89+（不支持 Firefox / Safari / 手机浏览器）
  • 一根能传数据的 USB 线（只供电的线不行）
  • 页面地址是 HTTPS 或 localhost（GitHub Pages 默认满足）
  • 设备：RDP-G01-W · ESP32-S3 · 16 MB flash

按上一条操作（不勾 Erase device）时，刷机只写引导程序、分区表与应用镜像， 设置与阅读记录保留；TF 卡上的书、划线、字体、壁纸也不受影响。

日常升级其实更推荐下面的 TF 卡本地升级：完全不擦除，风险最低。

三步刷完

  1. 连接设备：用能传数据的 USB 线接到电脑，设备保持开机即可（不用按 BOOT）。
  2. 点按钮选串口：选设备对应的那一项（常见名字带 USB JTAG 或 USB Serial）； 之后出现的 Erase device 确认框里不要勾选，直接点 Next。
  3. 等进度走完：写入约 3.6 MB；完成后设备重启，进入锁屏界面。之后可在「设置 → 升级和恢复 → 更新说明」里看到本版条目。

    • 深睡唤醒恢复小锁界面：深睡唤醒第一眼恢复为小锁界面（圆锁徽标），不再先显示上次锁屏缓存（壁纸）；解锁后仍回到原阅读位置。

    • 反色菜单/设置界面去残影：阅读工具栏二级/三级菜单每次打开/返回/切换后补压黑清理；反色下设置主/二级页面切换与列表滚动停下后也补压黑，菜单与设置页残影不再残留；浅色不变。
    • 小游戏进页全刷 + 分数叠影修复：进入四个小游戏时先自动整屏全刷一次（浅色 GC16、反色黑闪清理）；修复分数/状态旧字迹被新字叠一层的 bug（贪吃蛇/五子棋/俄罗斯方块状态行重画前清整行白底）。
    • 反色主页滑动清残影：反色模式下左右滑动主页/书架等主界面后追加满幅压黑清理（只压深色底、不白光），滑动不再让残影越积越重；浅色模式不变。
    • 反色到页自动全刷/左半残影修复：上一版为消除反色白闪让整屏 GC16 不再驱动深色底，补偿的压黑补扫在真机供数欠载时只扫完前半段（反色映射后正好是逻辑左半），图文页与主页周期清理还漏了补扫；本版压黑补扫改 FULL 标定扫描+127 行预填并覆盖整屏、补上缺失清理点，反色到页/手动整屏全刷改为「黑闪整屏清理」（瞬时压黑后重绘，清残影不白光）。
    • 深色（反色）白闪修复（重做 1.15.10）：反色下整屏 GL16/GC16 原本会先把深色等灰对（物理黑底）擦白再压回，每轮约 122ms 白闪；现在 1k LUT 正确保持逻辑 8–15 等灰对、只驱动真正变化的像素——普通/快刷/水波纹快刷/水波纹高清翻页、进书与整屏刷新都不再整片白闪。
    • 补黑与小游戏清理重做：翻页末尾补黑只压物理黑底（8 帧 FAST ≈56ms，不碰字形/白字、不改回差分基准）；进书/阅读周期清理/四个小游戏的周期清理都追加压黑清理，反色下分数/最高分旧字迹不再叠层，浅色模式零回归。
      • 修复透明书封/壁纸预览换图重启：预览缓存的灰度与 alpha 共用同一块 PSRAM，旧代码把两个指针都当独立分配 free，切换图片或退出预览时堆断言重启；现在只释放一次。崩溃后界面先回内建字体属异常启动恢复模式，再重启即恢复所选字体。
      • 流畅性：断电拆成两段——500ms 放电等待不再占显示锁，翻页/OTA 不用再等这 500ms；放电窗口内来新翻页会先正常拉低 EN 再完整上电，不会切断正在用的轨。
      • 自查修正：显示/OTA 递归锁改为开机即创建（此前只有进过升级页才创建，平时等于没有锁）；防泛白白推忽略待处理的全刷请求，久置到点不会变成整屏黑白闪。
      • 流畅性：整轨断电移到低优先级任务（含约 500ms 放电等待），主循环不再阻塞、不吞轻点/不拖慢长按；强光防反黑定为实验项默认关闭（NVS sun_fix=1 可开）。
      • 自查修正：断电任务与睡眠/关机路径用显示锁串行，避免两路同时写 SY7636A；强光防反黑不再默认开启（否则连续翻页每页多一次上下电）；去掉每个空闲周期的 INFO 日志。
      • 修复联网 OTA「内存不足」：旧门槛要求联网后内部 RAM 仍余 32KB、启动前内部余 48KB 且未先停蓝牙/未回收字形与表盘缓存，几乎必被判不足；现在按 OTA 真实分配分级门槛、先暂停蓝牙、启动前回收可重建缓存，并打印四项实测内存日志方便真机定位。
      • 缓解阅读页/票根锁屏久置发黑：①接通防泛白——静置满间隔（默认 5 分钟）用全像素 GL16 白推当前帧：白底吃 15→15 白推、黑字回纯黑、中灰保持，不压黑、不整屏闪；②强光防反黑（实验项，默认关闭，NVS `sun_fix` 可开）：开启后刷屏后高压轨 600ms 断电，且只在无触摸/菜单/OTA 时执行；含约 500ms 放电等待，需真机 A/B 后再定默认值。
      • 水波纹·高清字边更细（抗锯齿再加强）：高清档改用普通·高清的校准 GL16 表 + FULL 标定扫描（11090us/帧）；rc100 的 FAST 扫描帧仅约 7ms、脉宽约标定的 63%，抗锯齿中灰推不到位，字体边缘才粗糙。现在脉宽回到校准值，字边更细，动画仍约 0.82s。
      • 水波纹·高清抗锯齿加强：揭页条带 8→最多 32、动画约 0.53s→0.82s，用更长动画换更细的揭页前沿；抗锯齿仍在动画内完成（单次推屏、结束提交基准，不追加第二遍），快刷档不变。
      • 修复坚果云「同步阅读进度」闪退：云同步任务栈 8KB→12KB，进度同步路径栈占用≈3.3KB→1.3KB；合并结果按本机+云端实际条数分配并逐条边界校验（旧版 96 本以上会写越界）。

常见问题

点按钮没有反应 / 提示不支持

Web Serial 只在电脑版 Chrome、Edge（89+）以及 localhost / HTTPS 页面可用；Firefox、Safari、微信内置浏览器、手机浏览器都不支持。请把页面放在 https 地址（例如 GitHub Pages）或本机 python -m http.server 的 localhost 上打开。

串口列表里找不到设备

先在系统设备管理器里确认能看到 USB JTAG/serial debug unit（或 COM 口）；换一根能传数据的 USB 线；确认设备已开机。Windows 上个别机器需要允许浏览器访问串口设备。

刷机会不会清空我的书和设置？

按正常流程不会。刷写只覆盖引导程序、分区表、应用镜像和 OTA 元数据；书架文件在 TF 卡上，设置与阅读记录在 NVS 数据分区，都不会被动到。唯一会清空的情况是在 Erase device 确认框里勾选了擦除——那会整片擦掉 Flash。

已经不小心勾了 Erase device，记录丢了怎么办？

能恢复的：如果你之前在 设置 → 升级和恢复 → 保存与恢复 里保存过配置到 TF 卡（文件 Pico-settings.backup 在 TF 卡根目录），刷完后进同一个页面点「从 TF 卡恢复配置」，设置与阅读记录会回来。
本来就没丢的：TF 卡上的书、划线（.readpico）、字体、壁纸都还在，重新选一下字体/壁纸就能恢复外观。
找不回的：没有备份时，NVS 里的阅读进度、阅读时长统计、锁屏密码、Wi-Fi 密码、手势与按键映射会被清零，只能重设；另外内置存储 /flash/books 里的书也会随内部 FAT 分区一起被擦掉（TF 卡上的书不受影响）。

提示串口被占用 / 打不开端口

先关掉可能占用同一个串口的程序：idf.py monitor、串口助手、Arduino IDE 串口监视器、厂商刷机工具等，等几秒再点刷机。同一个浏览器标签页里重复刷机时，先让上一次连接断开（拔插一次数据线也可以）。

Windows 上需要装驱动吗？

设备是 ESP32-S3 的 USB-Serial-JTAG，Windows 10/11 会自动装好 usbser，一般不需要额外驱动。如果设备管理器里是黄色感叹号，重新插拔一次或换一个 USB 口（不要用只供电的集线器）。

怎么确认刷进去了、是这一版？

刷完开机后：设置 → 升级和恢复 → 更新说明，顶部新增了「坚果云同步 / Markdown / 手势」等条目；设置 → 连接与时间里能看到「坚果云同步」这一行。也可以对照本页的 sha256 与 TF 卡镜像校验值。

刷到一半失败 / 断线了怎么办

设备此时停在引导模式，重新连接再刷一次即可；重复刷同一份固件没有副作用。若设备反复重启，用 TF 卡升级方式兜底。

怎么回退到上一版？

和刷机一样：把上一版的 .bin 放 TF 卡根目录用本地升级，或用本页的刷机按钮刷入上一版镜像。分区布局没有变，回退不需要改引导程序。

Markdown 里的图片为什么不显示？

这一版 Markdown 只排版文字与结构，图片引用会显示成 [图] alt 占位；Obsidian 插件附带的 attachments/ 目录也不会被下载。图文混排仍在 EPUB 阅读里完整支持。
