# 页屿 PageIsle · 刷机与功能介绍

这是 **页屿 PageIsle**（基于 kiikoread 0.3.3-rc99 的应用层定制固件）的刷机页源码仓库。

- 在线页面：https://aleksandrov-eink.github.io/page-lsle/
- 浏览器一键刷机（USB / Web Serial）：页面上的「连接设备并刷机」
- TF 卡本地升级镜像：`firmware/Pico-update.bin`
- 固件信息：3,644,976 字节，sha256 `9e978db8eb238565dd25c442c5ba0fca7b45efcfc59c7c8bbf51cd62b3d43ca3`

刷机提示：确认框里**不要勾选 “Erase device”**，直接点「下一步」，设置与阅读记录会保留。

目录说明见 `README-DEPLOY.md`；第三方组件许可见 `THIRD_PARTY_NOTICES.md`。
