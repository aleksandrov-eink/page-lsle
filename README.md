# 页屿 PageIsle · 刷机与功能介绍

在线页面：https://aleksandrov-eink.github.io/pageisle/

- **正式版**：首页「浏览器一键刷机」使用 `firmware/`，当前正式镜像 sha256 `c49087aa…`
- **内测版**：在首页连续点击 5 次「页屿 PageIsle」标志展开内测通道（`beta/`），
  内测镜像为 `beta/firmware/`；确认稳定后才并入正式版
- 系统版本号独立于上游应用版本：页屿系统 1.15.20（2026-10-27）
- TF 卡本地升级镜像：`firmware/Pico-update.bin`

刷机提示：确认框里**不要勾选 “Erase device”**，直接点「下一步」，设置与阅读记录会保留。
